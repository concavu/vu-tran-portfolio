# Vũ Trần — Infrastructure Portfolio

A responsive, dark portfolio built with React, Vite, Tailwind CSS, Framer Motion, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Vite prints the local address after startup. To create a production build, run `npm run build`.

## Customize

- Edit project descriptions and technology tags in `src/App.jsx`.
- Update the architecture diagram there to match the deployed design.
- The contact action copies “Vũ Trần” so visitors can search their preferred channel; no email address or social profile has been assumed.
- Fonts load from Google Fonts; system sans-serif fallbacks are provided.
